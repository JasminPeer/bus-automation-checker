# Bus Automation Checker & Microservice Suite

Modular microservice modules verifying passenger crowd density, AI sensor integration, real-time Socket.io transmissions, database persistence, and threshold email notifications.

## 📁 Repository Structure
```text
bus-automation-checker/
├── index.js                                                       # Runner script
├── Fetch Passenger Count from AI Microservice.js                 # Ingestion module
├── Calculate Occupancy, Crowd Level, and Trigger Alerts.js       # Analytics engine
├── Store Occupancy Data in MongoDB.js                             # Persistence module
├── Broadcast Updates via Socket.io.js                             # Real-time stream
├── Send Occupancy Report via Email.js                             # Reporting module
└── package.json                                                   # Dependencies
```

## ⚙️ Prerequisites & Setup

### Requirements
- Basic familiarity with `JavaScript`
- Git installed on your local machine

### Installation Steps
```bash
git clone https://github.com/JasminPeer/bus-automation-checker.git
cd bus-automation-checker
npm install
node index.js
```
